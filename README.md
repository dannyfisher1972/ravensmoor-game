# Ravensmoor Hall (game prototype)

## Running it
```
npm run dev
```
Then open http://localhost:5173 in your browser.

## Controls
- WASD or Arrow keys to move
- Space to examine glowing objects or talk to NPCs

## What's here so far
A real Phaser 3 project (canvas/WebGL rendering, sprite-based movement, tile-based room)
using free CC0 Kenney.nl asset packs (Roguelike/RPG Pack for tiles, Tiny Dungeon for characters).
One explorable section of the manor is built out with 2 examinable evidence points and 2 talkable suspects,
as a vertical slice proving the mechanics before porting over the rest of the mystery
(all 36 evidence items, all 8 suspects, puzzles, and the accusation system).

Licenses for the asset packs are in public/assets/.
